# 错误清单

以下规则从历史错误中提炼，每条都被用户反复纠正过，必须严格遵守。

### 1. 派 agent 时禁止把含明文 key 的整份 .env 塞进 prompt

### 2. prompt 优化禁止用「反例对照」结构

### 3. SKILL.md不得依赖具体代码实现

### 4. 所有SKILL.md必须包含no_ai_style规则

### 5. Windows下curl传中文JSON必乱码

### 6. 项目AGENTS.md不存在时禁止动手

### 7. Copy-Item -Recurse 到已存在目录会产生嵌套副本

### 8. 公开仓库误提交后要重写历史，删文件不等于清除

### 9. 回收站不可靠，大文件可能被系统自动清空

### 10. 清理"已卸载软件残留"前必须交叉验证引用

### 11. 公开仓库推送前必须做隐私扫描

### 12. 凭记忆陈述规则归属导致串文件

全局 AGENTS.md 与工作区 AGENTS.md 职责不同，凭记忆引用内容已两次串文件（委派章节、同步脚本约定）。凡涉及规则归属陈述，必须先 Read 或 grep 对应文件核实，禁止凭记忆作答。
